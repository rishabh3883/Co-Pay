**2. Separating and Deploying Backend (Node + Express) on Render:**
- Go to Render Dashboard and click **New** -> **Web Service**.
- Connect the same `Co-Pay` git repository.
- Under **Service Settings**:
  - **Name**: `co-pay-backend`
  - **Runtime**: `Node`
  - **Root Directory**: `server`
  - **Build Command**: `npm install`
  - **Start Command**: `npm start`
- Click **Advanced** and add the Environment Variables:
  - `PORT`: `5000` or lock it to Render's dynamic port.
  - `JWT_SECRET`: `your_jwt_secret`
  - `SUPABASE_URL`: `your_supabase_postgresql_url`
  - `SUPABASE_KEY`: `your_supabase_anon_key`
- Render will start the build and start the Express server listening on the port. Once online, copy the generated Render URL (e.g. `https://co-pay-backend.onrender.com`) and append `/api` to use as the `VITE_API_BASE_URL` in your Vercel deployment.
